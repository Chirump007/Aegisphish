> **AegisPhish** is a modern cybersecurity web application built to eliminate credential loss from deceptive phishing attacks. Powered by an algorithmic Python heuristic engine and a sleek high-contrast UI, it checks suspicious links in real-time, monitors credential leaks, and promotes phishing-resistant Passkey (FIDO2) standards.

---

## 📌 The Problem It Solves

Over **85% of credential loss incidents** stem from deceptive phishing campaigns. Attackers register lookalike domain names (typosquatting like `paypa1.com` or `goog1e.com`) to impersonate legitimate authentication portals, tricking victims into giving away plain-text passwords and 2FA tokens.

**AegisPhish solves this by:**
1. **Pre-login Inspection:** Scanning suspicious URLs before users ever enter their credentials.
2. **Plain-English Threat Scoring:** Explaining technical indicators (entropy, character spoofing, homoglyphs) without confusing jargon.
3. **Phishing-Resistant Architecture:** Demonstrating how cryptographic **Passkeys (FIDO2/WebAuthn)** completely neutralize credential theft.

---

## 🚀 Key Features

* **⚡ Real-Time Heuristic Link Scanner (Python Backend):**
  * **Shannon Entropy Analysis:** Identifies randomly scrambled domain strings generated by automated phishing toolkits.
  * **Typosquatting & Homoglyph Detection:** Flags character substitutions (e.g., swapping `o` with `0` or `l` with `1`).
  * **Raw IP & Shortener Detection:** Catches attackers bypassing standard DNS or using services like `bit.ly` to hide destinations.
  * **Credential Trap Flags:** Detects suspicious token keywords (`login`, `verify`, `account-recovery`, `update-billing`).
  * **Disposable TLD Check:** Penalizes high-risk top-level domains commonly used in disposable phishing campaigns (`.xyz`, `.top`, `.click`, `.buzz`).

* **📦 3-Column Defense Grid (Bento Design):**
  * **AI Typosquatting Simulator:** Live interactive brand spoof checker.
  * **Credential Leak Checker:** Checks email records against known credential leak dumps.
  * **Passkey Immunity Hub:** Demonstrates why hardware/cryptographic authentication is immune to phishing.

* **🎯 "Spot the Fake" Phishing Arena:**
  * Side-by-side interactive browser inspection module showing a genuine portal vs. a spoofed credential harvester.
  * Interactive clue hotspots highlighting deceptive subdomains, fake SSL locks, and mismatched protocols.

* **🎨 Modern Visual Design:**
  * Deep matte charcoal background (`#0b0c0e`) with fine grain overlay.
  * Radial neon lime glow accents (`#c8f53c`).
  * Bold, clean sans-serif typography.
